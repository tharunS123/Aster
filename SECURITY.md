# Security policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/tharunS123/Aster/releases) gets security fixes.

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and click **Report a vulnerability**. Don't open a public issue or post details until the maintainer has replied.

Include Aster's version and build, your macOS version, the steps to reproduce, and what an attacker could do. Never attach dictated text, meeting text or other private content.

You'll get a reply from the maintainer. Aster is a small beta project, so there is no fixed response time and no bug bounty.

Note that Aster is ad hoc signed and not notarized, and its source code is private.
